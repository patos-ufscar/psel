Como Usar

(Antes de mais nada, peço desculpas por essa página, eu quis fazer algo mais bonitinho, mas eu obviamente não sou um designer.)

Logo acima, no setor de navegação, tem algumas opções de arquivos para você visualizar (eu estava sem criatividade para colocar arquivos de testes). "Patos" e "UFSCar" são imagens, "Grade BCC" é um PDF e "Doom" é o Doom rodando em um emulador de DOS feito em JS e WebAssembly (claro que isso já estava pronto).

Você pode ver o algoritmo Round Robin do Load Balancer funcionando pelo terminal, onde é possível ver para qual servidor backend está sendo roteado.

Este Load Balancer tem os métodos GET e POST implementados, então você pode enviar um arquivo via curl e pedir ele na URL, e seu arquivo deve ser mostrado sem problemas. Eu provavelmente coloquei um exemplo de como fazer isso no README do github.
